# Bosswebber

Marketing website for **Bosswebber** (bosswebber.com) — a freelance web & mobile app
development agency based in Rwanda, founded by Bosco Niyitegeka.

## Getting started

Requirements: Node.js & npm ([install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating)).

```sh
# Install dependencies
npm i

# Start the dev server with hot-reload
npm run dev

# Type-check / lint
npm run lint

# Production build
npm run build
```

## Tech stack

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
- Framer Motion
